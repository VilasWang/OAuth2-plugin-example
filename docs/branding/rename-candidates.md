# authforge 品牌更名调研报告 — 10 个候选名

> 调研日期：2026-08-24 ｜ 调研方式：域名注册局官方 RDAP 实查 + Web 品牌冲突检索 + PyPI/npm 包名查询
> 项目定位：高性能 C++ 开源 IAM 核心 + 商业增强模块

## 1. 背景

`authforge` 的问题：辨识度低（auth- 前缀与 Auth0 / Authing / Authelia / Authentik / Authress 等一长串同类挤在同一命名空间，且与 ForgeRock 共用 forge 词根），不利于建立独立品牌。

本次命名硬性约束：

- **禁止**直接使用 Identity / Access / Management 三个词及其组合；为最大化辨识度，本报告**同时全线避开 auth- 前缀**与 IAM 行业惯用词（gate、sentinel、bastion、vault、warden 等）；
- 仓库名避免俗套、简短易记、寓意积极；
- 优先调研可注册的 `.dev` / `.com` 域名；
- 不与 IAM 行业现有品牌冲突（Keycloak、Okta、Auth0、ForgeRock、Ory、Zitadel、Authentik、Authelia、Hanko、FusionAuth、Casdoor、Perun 等）。

**一个重要的现实约束**：2026 年的今天，所有常见英文词典词与著名神话名（signet、tessera、clavis、gungnir、mjolnir、aegis 等，共两批约 70 个）在 `.dev` 与 `.com` 上**均已被注册**（域名囤投资客持有）。因此可用域名的名字必然来自冷门语源或生僻语义词——本报告的候选正是按这个标准筛出的。

## 2. 调研方法与数据口径

| 项目 | 方法 | 判定 |
|---|---|---|
| `.dev` 域名 | Google Registry 官方 RDAP（pubapi.registry.google） | HTTP 404 = 未注册 |
| `.com` 域名 | Verisign 官方 RDAP | HTTP 404 = 未注册 |
| 品牌冲突 | Web 搜索同名软件 / 公司 / 开源项目 / 产品 | 人工判读 |
| PyPI / npm | 官方 registry API | 404 = 包名可用 |
| GitHub 用户名 | `api.github.com/users/<name>` | 404 = 用户/组织名未被占用（与仓库名无冲突，仓库可放自有组织下） |

局限性（务必阅读）：

1. RDAP"未注册"**不等于**标准价可注册——Google Registry 对部分 `.dev` 词设有 premium 溢价定价，实际价格以注册商报价为准；
2. 本报告**未做正式商标检索**，品牌冲突结论来自公开 Web 检索，不能替代 USPTO / EUIPO / CNIPA（重点第 9 类·软件、第 42 类·SaaS 与开发服务）的正式检索，非法律意见；
3. 域名状态为 2026-08-24 时点快照，未注册状态随时可能变化，**定名后应第一时间注册**。

## 4. 候选名详情

### 4.1 Yurushi（首选）

- **读音**：yoo-ROO-shee（ゆるし）
- **中文寓意说明**：日语「許し」＝**许可、授予**（宽宥）。IAM 系统的核心动作就是"判定并授予许可"——grant permission 的直译语源，语义契合度满分；日语音韵柔和易记，气质中性积极，无攻击性隐喻，适合"开源核心 + 商业增强"的双层品牌。
- **域名可用性评估**：十名中**资源最完整的一个**——`yurushi.dev` 与 `yurushi.com` **双双未注册**（唯一 .com 可得者）；PyPI、npm 包名均空。GitHub 个人用户名 `yurushi` 已被占用（仓库可置于自有组织下，不影响品牌）。
- **品牌冲突风险**：**低**。未检索到任何同名软件、公司或开源项目；最近似词为 Urushi（日语"漆"，及一个同名的日系 Web 组件框架，首字母不同、领域无关）。注意与 Urushi 的拼写区分度即可。
- **附注**：若倾向此名，建议**立即注册双域名**——`.com` 未注册的短词域名存活期以天计。

### 4.2 Zamek

- **读音**：ZAH-mek
- **中文寓意说明**：波兰语 **zamek** 一词双义——既是"**城堡**"又是"**锁**"。整个品牌故事一句话讲完："你的锁，是一座城堡。"安全不是一块插件，而是承重结构本身——非常契合用 C++ 从系统层构筑高性能核心的工程叙事。
- **域名可用性评估**：`zamek.dev` ✅ 未注册；`zamek.com` ❌ 已被注册；PyPI ✅、npm ✅。
- **品牌冲突风险**：**低**。无同名软件品牌；易混淆项为 Zamak（锌合金材料名词）与 Zamak Technologies（美国佛州 IT 托管商，拼写不同、非 IAM）。波兰语用户会心一笑，无负面含义。

### 4.3 Karamete

- **读音**：kah-rah-MEH-teh
- **中文寓意说明**：日语「**搦門**（搦手門）」——日式城堡中与正门（大手门）相对的**后门/侧门，专为己方可信者出入而设**。整个 IAM 的本质浓缩于一座城门：为可信者留一扇门，把不可信者挡在墙外。真实存在的建筑术语（茨城城、结城城等存有实例），冷僻但考据扎实，故事性在十名中最强，Logo 也好画（一道城门）。
- **域名可用性评估**：`karamete.dev` ✅；`karamete.com` ❌；PyPI ✅、npm ✅。
- **品牌冲突风险**：**低**。无同名软件/品牌；同名主要是土耳其人姓氏（Karamete），无商业冲突。

### 4.4 Arrha

- **读音**：AH-rah
- **中文寓意说明**：罗马法术语——缔约时交付的**信物/定金**，凭此物契约即告生效。这是 "token" 概念的古典祖先：凭证不是纸面声明，而是**交付到对方手中的实物信物**。寓意"每一枚令牌都是一份契约"，把技术令牌提升到了契约与信任的层面。
- **域名可用性评估**：`arrha.dev` ✅；`arrha.com` ❌；PyPI ✅、npm ✅。
- **品牌冲突风险**：**低**。同名软件/公司未检索到；近名 Arrah Tech（GitHub 小组织）拼写不同。

### 4.5 Virki

- **读音**：VEER-kee
- **中文寓意说明**：冰岛语/法罗语 **virki** ＝"**堡垒、要塞**"。五字母、两音节、拼读直觉，系统软件气质硬朗——"高性能 C++ 核心"本身就是数字堡垒。北欧语源与 Drogon 框架（冰火)一脉的硬核命名谱系气质相合。
- **域名可用性评估**：`virki.dev` ✅；`virki.com` ❌；PyPI ✅、npm ✅。
- **品牌冲突风险**：**低**。无同名产品/公司；同名主要是爱沙尼亚人姓氏（如科技记者 Tarmo Virki）与一处游戏地名，无商业冲突。

### 4.6 Salpa

- **读音**：SAHL-pah
- **中文寓意说明**：芬兰语 **salpa** ＝"**门闩**"；同时是 **萨拉防线（Salpalinja）** 之名——芬兰在整条东部边境修筑、且**从未被攻破**的防御工事线。双重意象：既是"落闩"的动作，又是"未失守"的战绩，防御语义纯粹而积极。
- **域名可用性评估**：`salpa.dev` ✅；`salpa.com` ❌；**PyPI ❌**（已被一个非安全领域的同名小包占用，SDK 需用 `salpa-sdk` 等后缀包名）；npm ✅。
- **品牌冲突风险**：**低**。无安全/软件品牌；生物圈的同名是樽海鞘（salpa 属），领域无关。

### 4.7 Portti

- **读音**：PORT-tee
- **中文寓意说明**：芬兰语 **portti** ＝"**大门、门径**"。十名中最朴素直白的一个：不渲染对抗，而强调"入口与欢迎"——契合"开源核心（门是开的）+ 商业增强（门后房间收费）"的双层定位。若品牌想走亲和开放路线，此名最合适。
- **域名可用性评估**：`portti.dev` ✅；`portti.com` ❌；PyPI ✅、npm ✅；**GitHub 用户名 `portti` 也未被占用**（十名中唯一，可注册同名 org）。
- **品牌冲突风险**：**低-中**。同名物有芬兰科幻杂志《Portti》、一个芬兰小众住户门户 App，及芬兰语普通名词的大量日常使用；无软件/安全行业品牌。

### 4.8 Tutamen

- **读音**：too-TAH-men
- **中文寓意说明**：拉丁语 **tutamen** ＝"**守护、防护之物**"。英国一英镑硬币边缘铸刻的拉丁铭文 "**Decus et Tutamen**"（华饰，亦是保障）——1662 年起铸于币缘以防银币被削剪；"铭刻在钱币边缘的守护"是极佳的品牌桥段（硬币亦是最古老的 token）。
- **域名可用性评估**：`tutamen.dev` ✅；`tutamen.com` ❌（为同名硬件公司持有）；PyPI ✅、npm ✅。
- **品牌冲突风险**：**中**。① GitHub 存有 2016 年 ACM SoCC 学术原型 `asayler/tutamen-socc16`（"下一代秘密存储平台"，安全邻域，久不活跃）；② **Tutamen**（tutamen.com，圣地亚哥/东莞，AI 数据中心散热硬件制造商，在营）。均非 IAM 行业，但同名在营公司的存在降低了此名的独占性。

### 4.9 Fulla

- **读音**：FUHL-lah
- **中文寓意说明**：北欧神话女神 **Fulla（芙拉）**——主神后 Frigg 的贴身侍从，**掌管她上了锁的宝匣与全部秘密**，是阿斯加德的"秘库守钥者"。凭据托管/密钥保管语义的神话原型，寓意精准。
- **域名可用性评估**：`fulla.dev` ✅；`fulla.com` ❌；PyPI ✅；**npm ❌**（同名包占用）。
- **品牌冲突风险**：**低-中（均在软件行业之外）**：Fulla 玩偶（中东知名娃娃品牌，母公司据报道已破产）、Schiit Audio 的 Fulla 耳放产品线。另，英语语感读起来像 "full-a"，品牌强度略弱。

### 4.10 Nuada

- **读音**：NOO-ah-dah
- **中文寓意说明**：爱尔兰神话至高王 **努阿达（Nuada）**，其佩剑"**必胜之裁**"是四秘宝之一——出鞘无人可逃脱裁决。授权判定的意象：当断则断、无可遁逃；其"银臂努阿达"失臂复权的故事亦有"身份凭证受损后重新取得合法性"的隐喻。
- **域名可用性评估**：`nuada.dev` ✅；`nuada.com` ❌；PyPI ✅；**npm ❌**。
- **品牌冲突风险**：**中**。存在两家同名在营创业公司：Nuada（葡萄牙，外骨骼手套，nuada.pt）与 Nuada（碳捕集，nuadaco2.com）。均非软件行业，但同名活跃公司有两家，且其中一家在欧有知名度。

## 6. 定名后的落地清单

1. **立即注册域名**（.dev 未注册状态随时可变；注意 Google Registry 对部分词的 premium 定价，以注册商报价为准；若选 Yurushi，`.com` 一并拿下）；
2. **正式商标检索/注册**：CNIPA（中国）、USPTO（美）、EUIPO（欧），第 9 类（软件）与第 42 类（SaaS/开发服务）；
3. **GitHub 仓库改名**：Settings → Change repository name，旧 URL 自动 301 重定向，不影响外链；
4. **客户端 SDK 包名**：PyPI / npm 以新名发布（若旧名被占则加 `-sdk` 后缀，如 salpa-sdk）；
5. 代码内标识（CMake 项目名、命名空间、openapi.yaml server URL 等）另行走版本化变更，与品牌域名解耦。
