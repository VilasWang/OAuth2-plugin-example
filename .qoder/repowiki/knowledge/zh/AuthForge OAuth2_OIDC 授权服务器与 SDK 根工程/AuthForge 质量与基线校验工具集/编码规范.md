- 每个工具通过 `argparse` 暴露 CLI，并以 exit code 0（通过）、1（检测到违规）、2（配置/环境错误）向 CI 反馈结果。
- C/C++ 源码分析统一采用逐字符状态机（code/line_comment/block_comment/string/char）剥离注释与字符串后再进行匹配，避免误报注释中的关键字。
- 基线类工具遵循“读取当前快照 → 与提交基线比对 → 仅当显式传入 `--update-baseline` 时才重写基线文件”的只读原则。
- 变更分类采用 ADDITIVE/BREAKING（或 M1–M5 等规则编号）二元标签，BREAKING 变更要求提升主版本号或经 `--force` 显式放行。
- 工具内部将受检目标（SDK libs、Domain libs、migrations、openapi.yaml）以模块级常量（如 `SDK_LIBS`、`DOMAIN_LIBS`、`POLICY`）集中声明，便于扩展与维护。
- 每个可复用的解析器（如 `parse_endpoints.py`、`api_diff.py`）附带 `--selftest` 模式，使用 `fixtures/` 下的最小样例进行自测，确保解析/渲染往返无损。
