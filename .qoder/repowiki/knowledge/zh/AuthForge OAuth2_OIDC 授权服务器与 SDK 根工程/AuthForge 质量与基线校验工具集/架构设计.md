本模块是纯 Python/Shell 的辅助工具集合，按职责划分为若干独立子目录：
- `api-diff/`：通过状态机剥离 C/C++ 注释与函数体，生成 SDK `libs/*/include` 头文件的声明骨架，并与 `api-baseline.txt` 对比，强制 SemVer 主版本升级策略（breaking 需提升 cmake/Version.cmake + CMakeLists.txt + conanfile.py 三处版本）。
- `arch-guard/`：对 `libs/common|oauth2|identity` 的 `include/`、`src/` 源码执行 R1（禁止 `#include <drogon/...>`）、R2（oauth2 与 identity 互引禁止）、R3（禁止 `drogon::orm`）三层架构守卫。
- `migration-check/`：校验 `apps/server/migrations/*.sql` 的文件命名（M1）、版本连续性（M2）、幂等性（M3）、不可破坏性（M4），并通过 SHA-256 锁定已应用迁移内容（M5），基线由 `baseline.json` 管理。
- `refactor-baseline/`：包含 OpenAPI 端点提取器 `parse_endpoints.py`（自带 PyYAML 回退的最小 YAML 解析器）、Playwright/CTest 输出解析器，以及 `endpoints/`、`playwright/`、`ctest/` 下的签名基线文件；配套 `capture.sh`/`capture.ps1` 用于跨平台捕获。
- `security/dependency_eol_check.py`：解析 `conan.lock`，对照内置 POLICY 表（openssl ≥ 3.0、zlib ≥ 1.2.13、libcurl ≥ 8.4.0）检查运行时依赖是否低于安全底线。
- 顶层脚本：`diff-endpoint-baseline.py` 复用 `parse_endpoints` 对当前 OpenAPI 与 `refactor-baseline/endpoints/openapi.signature.txt` 做差异报告；`api-test-coverage-check.py` 比较 PowerShell 与 Bash 测试脚本覆盖的端点集合；`refactor-doc-paths.py` 在 Markdown 非代码段内批量替换旧文档路径。
- `test/scripts/` 存放工具自身的单元测试与迁移脚本。
所有工具均遵循“只读仓库 + 可选 `--update-baseline`”模式，通过 exit code 0/1/2 区分成功、违规与配置错误，便于嵌入 CI。
