本模块按部署目标划分为四个并列子目录：`docker/` 通过单文件多阶段 `Dockerfile`（backend-base → backend-dev → backend-builder → backend-runtime → frontend-builder → frontend-runtime）统一构建 Drogon C++ 后端与 Vue SPA，并配合 `docker-compose.{debug,prod}.yml` 编排；`helm/authforge/` 是 Helm v2 Chart，以 `Chart.yaml` 声明应用版本，`templates/` 下每个资源一个 YAML（backend/frontend/admin ingress、configmap/secret/postgresql/redis/migration-job），通过 `values.yaml` 与 `values-local.yaml` 区分环境；`nginx/nginx.conf` 定义 HTTPS 入口、速率限制（login/api 双 zone）、TLS 1.2+ 与安全头，并将 `/api`、`/oauth2`、`/.well-known`、`/health`、`/metrics`、`/admin`、`/` 分别转发至后端或前端服务；`env/` 提供 `server.env.example` 与 `docker.env.example` 作为运行时环境变量模板，覆盖 `config.json` 默认值；`observability/prometheus.yml` 暴露指标抓取配置。依赖方向单向：所有编排产物均消费由仓库根脚本 `scripts/backend/build.sh` 产出的静态链接二进制，不引入额外构建逻辑。
