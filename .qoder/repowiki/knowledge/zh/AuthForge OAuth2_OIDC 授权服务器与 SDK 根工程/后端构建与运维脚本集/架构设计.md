脚本按职责分层组织：`scripts/backend/` 是核心子目录，通过 `env_common.sh/.bat` 统一加载仓库根 `paths.env` 中的路径变量（`OAUTH2_SERVER_DIR`、`BUILD_DIR`、`COMPOSE_FILE_REL` 等），并导出 `resolve_cmake_preset` 函数将 OS + 构建类型 + sanitizer 映射到 `CMakePresets.json` 中的 preset 名；所有构建/测试脚本（`build.sh/.bat`、`test.sh/.bat`、`full-test*.sh/.bat`）均基于该公共环境调用 Conan 安装依赖、`cmake --preset` 配置与构建、`ctest` 执行用例，并通过 `run-server.sh/.bat` 启动服务。

- 构建层：`build.sh/.bat` 解析参数（`--debug/--release/--asan/--tsan/--install-deps`），自动初始化 Conan profile、清理 `CMakeUserPresets.json`、把 `drogon_ctl` 加入 PATH，并在构建产物旁拷贝 `config.json`。
- 测试层：`test.sh/.bat` 用 ctest 跑两遍（标准 `config.json` 与 `config.ci.json`）；`full-test*.sh/.bat` 在 Docker 中拉起 Postgres 再执行集成测试；`test-admin-endpoints.*` / `test-oauth2-endpoints.*` 针对特定 API 子集。
- 运维层：`setup-database.sh/.bat`、`docker-postgres-*.sh`、`rebuild-debug-image.sh`、`cleanup-docker.sh` 管理数据库与容器生命周期；`reset-admin-password.*`、`reset-account-lockout.*` 用于账号重置。
- 顶层脚本：`security-check.sh` 扫描误提交密钥与 `.gitignore` 规则；`smoke-parity.sh/.ps1` 通过 `manage.sh` 串联 build/test/run/docker-up/down 五步冒烟流程验证前后端一致性；`generate-certs.sh`、`generate-jwt-keys.sh`、`measure_coverage.py`、`emoji_manager.py`、`check-doc-links.sh`、`test-frontend-url-config.sh` 为独立工具。

依赖方向单向：具体脚本 → `env_common.*` → `paths.env`；不反向引用项目源码，仅通过绝对路径访问构建产物与配置文件。
