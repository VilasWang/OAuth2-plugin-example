- Pinia store 通过 `defineStore('auth', () => {...})` 组合式 API 定义，并以 `isAuthenticated` 计算属性暴露鉴权状态，供路由守卫与页面消费。
- 所有 HTTP 错误统一经 `normalizeError(e)` 转换为 `NormalizedError` 后再展示给用户，禁止在视图层直接读取 `e.response.data.*`。
- 刷新令牌仅保存在 `sessionStorage`（而非 localStorage），访问令牌仅驻留内存，以降低 XSS 泄露风险。
- 401 响应触发去重化的 `refreshAccessToken()`（共享 `refreshInFlight` Promise），避免并发刷新导致后端 refresh token 被提前轮换而登出。
- 错误消息通过 `services/messages/zh-CN.ts` 的 `getErrorMessage(code, locale)` 解析，默认语言固定为 zh-CN，新增错误码需同时更新 catalog。
- admin 与 user 的 `errorAdapter.ts` 保持字节级一致，由 `crossAppConsistency.property.test.ts` 断言两端行为等价，确保跨应用错误体验统一。
