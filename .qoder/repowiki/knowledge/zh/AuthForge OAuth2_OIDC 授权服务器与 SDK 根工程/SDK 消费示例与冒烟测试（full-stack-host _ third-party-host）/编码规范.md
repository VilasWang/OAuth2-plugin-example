- 示例程序通过自定义的轻量断言宏/函数（如 `check`、`CHECK`）打印 `[ ok ]`/`[FAIL]` 到 stderr 并累计失败计数，最终以 `std::_Exit(0|1)` 或 `return 0/1` 暴露为冒烟测试信号。
- HTTP 服务端启动采用“后台线程 + `registerBeginningAdvice` 回调 + `std::promise/future`”模式，确保控制器注册与依赖装配完成后才向主线程发出就绪信号。
- 通过 `find_package(authforge-*)` 消费 SDK 而非 `add_subdirectory`，并在 CMakeLists.txt 中以 `target_link_libraries(... PRIVATE authforge::xxx)` 显式声明依赖，模拟真实第三方消费者的链接方式。
- 存储与加密后端统一使用内存实现（`Memory*Repository`、`FakeCryptoProvider`），使示例在无外部 DB/Redis 的情况下保持可重复、可隔离的冒烟行为。
