- 每个功能域封装为一个独立 `.cmake` 文件，并通过 `include_guard(GLOBAL)` 防止重复加载。
- 对外暴露的均为函数式 API（如 `authforge_package`、`oauth2_apply_*`），而非 INTERFACE 库，以保证所有编译/链接选项均为 PRIVATE，不泄露到导出目标。
- 函数入口统一先校验传入 target 是否存在，不存在则 `message(FATAL_ERROR ...)` 终止配置。
- 编译器差异通过 `if(MSVC) / else()` 分支处理，MSVC 使用 `/W4`、`/FI`、`/WX` 等参数，GCC/Clang 使用 `-Wall -Wextra`、`-include`、`-Werror` 等对应参数。
- 可选特性（Sanitizer、Coverage、Werror）均以 `option(... CACHE STRING/OPTION ...)` 形式暴露为可缓存布尔或枚举变量，默认关闭，非目标平台时发出 WARNING 而非 FATAL。
- 全局常量（版本号、模块目录、构建产物根路径）统一以 `CACHE INTERNAL` 变量声明，并在首次 include 时捕获 `CMAKE_CURRENT_LIST_DIR` 避免作用域漂移。
