- 每个子包均声明为 STATIC 库并通过 `add_library(authforge::<name> ALIAS ...)` 暴露命名空间别名，便于消费者以 `target_link_libraries(... authforge::*)` 方式引用。
- Domain 层（common/oauth2/identity）的 CMakeLists.txt 顶部以注释形式声明 design.md §4.1 rule 1 的架构约束（禁止依赖 Drogon、禁止循环依赖），由人工审查而非工具强制。
- 所有子包统一调用 `oauth2_apply_compat()`、`oauth2_apply_warnings()`、`oauth2_apply_gcov()` 三个共享 CMake 宏来设置编译器兼容、警告级别与覆盖率开关。
- 通过 `authforge_package(TARGET ... PACKAGE ... EXPORT_NAME ... DEPENDENCIES ...)` 集中声明安装与 find_package() 导出元数据，使每个库成为独立可安装的 SDK 包。
- 可选特性（WebAuthn、Social）在 CMake 中通过 `option(WITH_*)` 控制，并同时从源列表条件性加入 `.cc` 文件与 `target_compile_definitions(PUBLIC WITH_*)`，确保头文件中的 `#ifdef WITH_*` 守卫一致生效。
- 存储适配器统一实现 `authforge::oauth2::repository::*` 接口（如 IClientRepository/IGrantRepository/ITokenRepository/IConsentRepository），并由各自的 *RepositoryBundle 聚合，保持 Domain 接口与具体存储解耦。
