文档按角色与生命周期分层组织：`backend/` 存放当前系统的技术文档（架构概览、安全、RBAC、SDK 集成、OpenAPI/Swagger UI、CI/CD、数据持久化等）；`ops/` 聚焦生产部署、安全检查与验证清单；`admin/` 与 `frontend/` 记录管理端与用户端的 E2E 测试指南与用例；`productization-evolution/` 保存产品化路线图、基准设施设计与竞品调研；`history/` 作为只读归档区，保留 PRD、design（含 superpowers 计划的 plans/specs/validation）、前端旧版设计等历史材料，并在其 README 中明确标注“冻结不更新”。入口为根级 `docs/README.md`，以导航索引形式将读者引导至各子目录的对应指南，形成单一文档入口 + 多主题分支的结构。
