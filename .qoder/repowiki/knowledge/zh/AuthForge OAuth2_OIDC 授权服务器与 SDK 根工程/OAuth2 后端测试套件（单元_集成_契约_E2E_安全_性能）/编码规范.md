- 所有测试通过 `DROGON_TEST` 宏注册，并以 `Integration_P0_Contract_*` 等命名约定区分优先级与领域，便于 CTest 按名称精确选择。
- 多后端契约测试统一通过 `get*ClientOrNull()` 探测 Postgres/Redis 可用性，返回 `nullptr` 时直接 `return;` 跳过该用例而非失败。
- 异步仓库 API 的断言统一封装为 `waitForValue`/`waitForVoid`，内部用 `std::promise`/`std::future` 配合 30 秒超时等待回调完成。
- 测试间隔离使用 RAII 事务守卫 `TestTransaction`，构造时 `BEGIN`，析构时 `ROLLBACK`，确保每次测试后数据库状态回滚。
- 并发相关测试通过 `#if defined(__SANITIZE_THREAD__)`/`__SANITIZE_ADDRESS__` 检测 sanitizer 环境，并以 `inline constexpr bool kTsanEnabled/kAsanEnabled` 作为运行时门控，使同一份代码在正常构建下走安全路径、在 sanitizer 构建下触发真实竞态。
- 测试配置加载统一经由 `loadConfigWithEnv` 读取 JSON 配置文件并按环境变量覆盖 DB/Redis/客户端密钥，同时禁用 daemonize/relaunch_on_error/handle_sig_term 以避免 fork 破坏 promise/future 同步。
