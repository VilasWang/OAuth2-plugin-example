测试套件以 `tests/test_main.cc` 为唯一入口：启动一个独立的 Drogon HTTP 事件循环线程，在 `registerBeginningAdvice` 中调用 `bootstrap::wireControllerPluginDependencies()` 和 `bootstrap::wireIdentityServices()` 完成控制器与插件依赖装配，再调用 `test::run()` 执行所有 DROGON_TEST 用例。

- 目录分层按测试类型划分：`unit/`（无外部依赖的组件级测试）、`integration/`（通过 HTTP 访问运行中的服务器，含 admin/auth/controllers/storage/token/concurrency/error/plugin 子域）、`e2e-backend/oauth2_flows/`（完整 OAuth2 流程）、`contract/`（对 IClientRepository/IGrantRepository/ITokenRepository/IConsentRepository/UserInfoRepository 的多后端契约验证）、`security/injection/`（注入与数据库连接泄漏验证）、`performance/benchmark/`（基准）。
- 共享基础设施集中在 `common/`：`TestBase.h` 提供 RAII 事务守卫 `TestTransaction`；`test_categories.h` 定义 `TestCategory`/`TestPriority` 枚举；`HttpTestClient.h`、`SocialMockFixture.h`、`StorageSeed.h`、`OpenApiGeneratorTest.cc` 等提供 HTTP 客户端、社交登录模拟、数据库种子与 OpenAPI 生成器辅助。
- `contract/ContractFixtures.h` 封装多后端（Postgres/Redis/Memory）可用性探测、异步回调等待（`waitForValue`/`waitForVoid`）与唯一 ID 生成，使每个仓库接口 × 每个后端形成 N×M 个独立命名的 DROGON_TEST 用例。
- `integration/concurrency/ConcurrencyRaceSupport.h` 提供 TSan/ASan 运行时门控（`kTsanEnabled`/`kAsanEnabled`）、`SpinBarrier`、`PendingCallbacks`、`InterleavingGenerator` 等工具，用于复现 Category B/C 并发竞态与生命周期问题。
- CMake 将所有层级源文件合并编译为单一 `authforge-tests` 可执行目标，并通过 `add_test(NAME OAuth2Tests ...)` 注册到 ctest；契约测试通过 `foreach` 将每个用例单独 `add_test` 并打上 `LABELS "Contract"`，支持 `ctest -L Contract` 筛选。
- 构建期通过 `OAUTH2_MIGRATIONS_DIR`、`OAUTH2_SEED_DIR`、`OAUTH2_GOLDEN_DIR`、`OAUTH2_DOC_API_REFERENCE` 等编译常量注入迁移 SQL、种子数据、Golden 快照与文档路径，供 `SchemaSetup.cc` 与 `common/StorageSeed.h` 在运行时使用。
