### arch-guard
- 定义：项目架构守卫工具（位于 `tools/arch-guard`），扫描 `libs/` 源码 include，强制三条铁律：domain 层（common/oauth2/identity）禁止 include `<drogon/...>`；oauth2 与 identity 两个 SDK 域零互相 include；domain 层不得使用 `drogon::orm`（ORM 仅限 storage-postgres）。违规即 exit 1，接入 CI 门禁。
- 别名：arch guard

### SdkSmoke
- 定义：CTest 标签，用于标记全栈 build-tree SDK 冒烟测试。通过 `ctest --build-and-test` 启动 standalone 示例工程，经 `find_package(authforge-drogon CONFIG)` 消费整套产品栈闭包，真实起 HTTP 服务断言路由注册、配置驱动插件实例化、视图渲染和授权码流入口。
- 别名：SDK smoke、full-stack smoke

### Task 28a / Task 28b
- 定义：tasks.md 中的里程碑任务编号。28b 证明纯引擎形态可装配跑授权码流；28a 补全 SDK 打包机制（Config.cmake.in/find_dependency/export）和全栈 HTTP smoke，是 Task 32（CI 门禁）和 Task 36（release 打 SDK 产物）的前置。

### Test 11b
- 定义：admin 端点测试套件中的一个用例，测试 `DELETE /api/admin/tokens/:tokenPrefix` 撤销接口。缺陷在于它从列表取 `tokens[0]` 的前缀去删，而整个套件复用同一个 admin 会话 token，导致 Test 11b 把自身会话也删掉，后续测试全部 401 级联失败。修复方式为额外签发一次性 token 专供撤销。

### preset 迁移
- 定义：将项目从裸 `cmake ..` + 系统包路径的构建方式，统一迁移到 `Conan + cmake --preset`，构建目录约定为 `build/<preset-name>`（如 `build/linux-release`、`build/windows-msvc`、`build/macos-arm64`），并新增 debug preset。覆盖本地脚本、CI 三平台 workflow 及文档。
- 别名：Conan+preset 迁移

### TokenManagementService
- 定义：重构后从 AdminController 抽离出的独立 service，实现 token 列表查询、按前缀撤销（`deleteBy(Criteria(_token, Like, prefix%))`）、`token_prefix = substr(0,8)` 计算等能力；被 admin 端点测试套件直接调用。

### OAuth2Plugin
- 定义：Drogon 插件，通过配置文件 `plugins[].name="OAuth2Plugin"` 反射实例化，负责 OAuth2/OIDC 协议端点（authorize/token/discovery 等）以及 client/repository 的内存/Redis/Postgres 后端装配。
- 别名：oauth2 plugin

### full-stack-host
- 定义：`examples/full-stack-host/` 下的 standalone 示例工程，通过 `find_package(authforge-drogon CONFIG)` 消费整套产品栈闭包，复用 `apps/server` 的 bootstrap/organization 源和 views，memory 后端 hermetic 起真 HTTP 服务，作为 SdkSmoke 的验证宿主。
