ORM model classes (anything under `models/`) are generated by `drogon_ctl` from
the live database schema. NEVER hand-edit them — to change a model, update the
schema then re-run `/orm-gen`. Edits are silently overwritten on the next
regeneration.

A PreToolUse hook also blocks writes to `models/**`, but keep this in mind
while writing so the failure is never a surprise.
